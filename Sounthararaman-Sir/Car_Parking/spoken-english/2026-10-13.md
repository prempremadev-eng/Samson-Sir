# 🗣️ Spoken English Practice – 2026-10-13

Topics: recall quiz, cards vs tables, `<span>` vs `<div>`, flexbox, column names.

How to practise: read each line **out loud 3 times**. Then cover it and say it from memory.

---

## 1. Talking about what I did today

> "Tonight I changed my Dashboard from a table to cards.
> Each vehicle now has its own box with the number, the status, the type and the time.
> I also wrote the CSS for the cards, and it looks like the original app."

---

## 2. The recall quiz

- "I did a recall quiz before starting, and I got five out of eight."
- "I knew most of the answers, but I forgot to explain why."
- "I forgot that a string doesn't have a map method."

---

## 3. Cards and HTML

- "Cards are better than a table on a small phone screen."
- "A span stays on the same line, but a div starts a new line."
- "If a value is empty, React just shows nothing. It doesn't crash."

---

## 4. CSS

- "I removed the bullets with list-style none."
- "Display flex puts the items in a row."
- "Space-between pushes one item to the left and the other to the right."
- "I added a border, rounded corners and some padding to each card."

---

## 5. My mistakes

- "I typed the column names wrong. They need a capital letter."
- "I used a variable name instead of the real column name."
- "I fixed the code, but I forgot to save the file."
- "Next time, I'll copy the column names from the API response."

---

## 6. Useful phrases

- "Let me check the column names first."
- "I think it will show bullets, because it's a list."
- "Could you check my CSS, please?"
- "How much is left on the Dashboard?"
