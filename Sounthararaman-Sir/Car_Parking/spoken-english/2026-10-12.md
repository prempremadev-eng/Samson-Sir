## 2. `useEffect` and StrictMode

- "If I fetch directly inside the component, it causes an infinite loop."
- "useEffect with an empty array runs only once."
- "In development, StrictMode runs the effect twice to find bugs."
- "Reading twice is fine, but saving twice would create duplicate rows."
- "That's why POST happens on a button click, and GET happens in useEffect."

---

## 3. Fetching and storing data

- "The useEffect function can't be async, so I create an async function inside it."
- "I have to call the function, otherwise nothing happens."
- "I store the rows in state, so they don't disappear when React re-renders."
- "The initial value is an empty array, because the data will be an array."
- "An object doesn't have a length, but an array does."

## 4. `map` and `key`

- "map runs the same code for every item and returns a new list."

- "I used ROWID as the key, because Catalyst makes it unique."
- "The key goes on the outer tag that map returns."
