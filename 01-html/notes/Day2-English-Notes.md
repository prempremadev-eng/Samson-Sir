# Day 2: Headings, Paragraphs, Text Tags (English notes)

Date: 2026-10-09 · Practice file: `about.html`

## 1. Headings `h1` to `h6`

Headings show how important a piece of text is.

- `h1` is the biggest and most important. Use it once per page.
- `h6` is the smallest. It is even smaller than normal text.
- There is no `h7`. The browser shows it as normal text and gives no error.

## 2. `<br>` (line break)

The browser treats Enter like a space. To start a new line, we use `<br>`.
Three lines need two `<br>` tags. `<br>` has no closing tag because it has no content.

## 3. `<hr>` (horizontal rule)

`<hr>` draws a line between two sections. By default it is full width. It has no closing tag.

## 4. `<strong>` and `<em>`

| Tag | Looks like | Meaning |
|---|---|---|
| `<strong>` | bold | This is important |
| `<em>` | italic | Say this word with stress |

Both have content, so both need a closing tag.

## 5. Nesting

A tag inside another tag: `<strong><em>tasty</em></strong>`. The inner tag closes first.

## 6. Block vs inline

| Type | Behaviour | Examples |
|---|---|---|
| Block | Takes the full width and starts on a new line | `h1`–`h6`, `p`, `hr` |
| Inline | Stays inside the line and takes only the space it needs | `strong`, `em` |

## 7. Vocabulary

| Word | Meaning |
|---|---|
| heading | a title |
| line break | a new line |
| emphasis | stress on a word |
| nesting | putting one thing inside another |
| empty tag | a tag with no content and no closing tag |

### Word order tip

English order: **what** → **where** → **how it is**.

| Tamil order | English order |
|---|---|
| Bus stand **near** | **near** the bus stand |
| Kumbakonam bus stand near degree coffee tasty | **The degree coffee** near Kumbakonam bus stand **is very tasty** |
