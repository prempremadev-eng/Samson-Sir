# Day 1: HTML Tags + Page Skeleton (English notes)

Date: 2026-10-09

## 1. What is HTML and why do we need it?

A browser cannot "see" like we do. If we give it plain text, it does not know which part is a heading and which is a paragraph.

> **HTML puts a label (tag) on each piece of content and tells the browser what that content is.**

## 2. Parts of a tag

```html
<h1>Vanakkam</h1>
```

| Part | Name |
|---|---|
| `<h1>` | Opening tag |
| `Vanakkam` | Content |
| `</h1>` | Closing tag (has a `/`) |

The browser does not show tags on the screen. It shows only the content.

## 3. Page skeleton

| Tag | Why we need it |
|---|---|
| `<!DOCTYPE html>` | Tells the browser that this document follows HTML5 rules |
| `<html>` | Holds all the code of the page |
| `<head>` | Holds information about the page. It is not shown on the screen |
| `<body>` | Holds everything shown on the screen |
| `<title>` | The page name shown in the browser tab |

## 4. What I found

- Without `<title>`, the tab shows the file path.
- With `<title>`, the tab shows "Prem's First Page".

## 5. Vocabulary

| Word | Meaning |
|---|---|
| tag | a label like `<h1>` |
| opening tag / closing tag | start label / end label |
| content | what is inside the tags |
| indent | spaces at the start of a line |
| typo | a spelling mistake |
